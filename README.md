# Mad Libs Generator

A simple interactive command-line Mad Libs game written in Python. Users can choose from three story templates (or let the program pick a random one) and fill in parts of speech to generate funny stories.

## Story Templates
1. **Hospital Visit** – A story about a funny experience at a hospital.
2. **Camping Trip** – An outdoor adventure story featuring camping, wildlife, and campfires.
3. **Enchanted Castle** – A letter written from a magical castle in a faraway land.
4. **Random Template** – Automatically picks one of the three stories at random using Python's `random` module.

## Requirements
- Python 3.x (no external libraries or dependencies required)

## How to Run
1. Make sure Python is installed on your computer.
2. Save the code in a Python file (e.g., `mad_libs.py`).
3. Open your terminal or command prompt and navigate to the folder where the file is saved.
4. Run the script using the following command:
   ```bash
   python mad_libs.py
